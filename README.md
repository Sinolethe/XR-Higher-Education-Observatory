# XR Higher Education Observatory

A Digital Humanities research platform for the comparative analysis of XR projects in German and Swiss universities.

## 📌 Project Overview

This repository contains the methodological core and technical infrastructure (Chapter 4) of the dissertation *“Extended Reality in Higher Education.”* The goal of the **XR Higher Education Observatory** is the systematic documentation, analysis, and visualization of XR applications with regard to their epistemic functions and aspects of educational equity.

## 🔬 Research Questions

- Distribution of XR projects
- Epistemic functions of XR
- Educational justice and accessibility

## 📊 Metadata Schema

The database is divided into the following tables:

- `Table 1: Projects` (Core data of university projects)
- `Table 2: Technology & Infrastructure` (Technical foundations such as OpenXR, Unity, etc.)
- `Table 3: Epistemic Profile` (Recording of cognitive and spatial dimensions for the XREI score)
- `Table 4: Accessibility` (Accessibility and motion sickness reduction)
- `Table 5: Evidence` (Citations and references to ensure scientific validity)

## 🛠️ Technologies

- 🐍 **Python** — The primary programming language for data processing and automation.
- 🗄️ **SQLite** — The relational database for storing the metadata schema.
- 🐼 **Pandas** — The data analysis library for structuring university projects.
- 📓 **Jupyter Notebook** — The interactive environment for research design and XREI calculation.
